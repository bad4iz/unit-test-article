# ProfilePanel: пример к статье

В `src/ProfilePanel.before.tsx` сохранён исходный компонент без входных пропсов. После рефакторинга `ProfilePanel` получает из `useSetupProfilePanel` признак загрузки и готовые пропсы карточки через деструктуризацию. Подготовка данных находится в хуке, разметка — в компоненте.

Для запуска подойдёт Node.js 22 от версии 22.12 или Node.js 24.

Из корня репозитория:

```bash
cd examples/profile-panel
npm ci
npm test
npm run typecheck
```

В `package-lock.json` закреплены зависимости. Основные версии: Shallowly 1.1.1, React 19.2.4, Vitest 4.0.18 и TypeScript 5.9.3.

- `src/ProfilePanel.shallow.test.jsx`: три проверки разметки и передачи пропсов. Подменяется только `useSetupProfilePanel`. Обработчики не вызываются, внутренности `UserCard` не выполняются.
- `src/useSetupProfilePanel.test.jsx`: две проверки подготовки данных через `renderHook`. Подменяется источник данных `useProfile`.
- `src/ProfilePanel.dom.test.jsx`: одна проверка с настоящими хуками и карточкой. Кнопка раскрывает и скрывает детали в jsdom.

Тесты оформлены как в Shallowly: `🐛 describe`, `🧪 it` и блоки Arrange / Act / Assert. В начале каждого теста с моками вызывается `mockDefault()`: он задаёт исходные данные, которые при необходимости меняются для конкретного сценария. `beforeEach` в тестах нет. Моки автоматически сбрасываются через `mockReset: true` в конфиге Vitest, а `restoreMocks: true` восстанавливает методы, подменённые через `vi.spyOn`. Очистка DOM после каждого теста подключена один раз в `vitest.setup.ts`.

Тесты написаны на JavaScript: `vi.mock('./hook')` подменяет модуль, ответ задаётся напрямую через `hook.mockReturnValue(...)`. Данные конкретного сценария видны в его Arrange. `npm test` запускает эти тесты, а `npm run typecheck` проверяет TypeScript-код компонентов, хуков и конфигурации.

В настоящем `useProfile` лежит локальный профиль с именем `имя из профиля`. Запросов к серверу нет. В изолированных проверках используется `имя из хука`, чтобы заметить захардкоженное имя. DOM-тест проверяет взаимодействие с React в jsdom; настоящий браузер не запускается.
