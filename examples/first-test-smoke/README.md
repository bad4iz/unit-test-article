# Первый smoke-тест

Учебный пример: сначала запускаем код с одним подготовленным сценарием, затем добавляем проверки результата. Это маленькая панель профиля; сетевых запросов и приватного кода приложения здесь нет.

Нужен Node.js 22 (не ниже 22.12) или 24. Из этой папки:

```bash
npm ci
npm test
```

Шесть тестов:

- `useSetupProfilePanel.test.js`: минимальный smoke, имя из профиля, загрузка без данных карточки;
- `ProfilePanel.test.jsx`: минимальный shallow-smoke, заголовок и имя для карточки, разметка загрузки.

В каждом тесте явно вызывается `mockDefault()` с JSDoc. Ответы зависимостей задаются через прямой `mockReturnValue` на импортированных функциях после `vi.mock()`. `mockReset: true` и `restoreMocks: true` настроены в Vitest; сценарные `beforeEach`/`afterEach` не нужны.

Первый тест setup-хука проверяет только то, что вызов завершился и вернул не `undefined`. Даже неверное имя внутри объекта он пропустит. `expect.hasAssertions()` гарантирует, что была выполнена хотя бы одна проверка, но не делает слабое ожидание содержательнее. Следующий тест уже проверяет конкретные данные и поэтому замечает подмену имени.

`useSetupProfilePanel()` вызывается напрямую только в этих изолированных тестах: `useProfile` полностью замокан, а в самом setup-хуке нет прямых вызовов `useState`, `useEffect` и других React-хуков. Настоящий `useProfile` использует `useState`, но здесь его тело не исполняется. Если в setup-хуке появится настоящий React-хук, такой прямой вызов уже не подходит — понадобится React-окружение, например `renderHook`.

Shallowly проверяет результат сборки React-элементов без DOM и исполнения дочернего `UserCard`. Успешный smoke не подтверждает правильность всей страницы, поведение браузера или взаимодействие настоящих хуков. Колбэки дочерних компонентов в примере не вызываются.

Контрольный эксперимент для статьи: заменить в `useSetupProfilePanel.js` выражение `state.profile.name` на строку `'чужое имя'`. Smoke по-прежнему проходит, а проверка имени падает. После эксперимента вернуть исходное выражение. Эта подмена не входит в сохранённую реализацию.
