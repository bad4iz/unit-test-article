## Как обновлять статьи

1. Найти актуальный исходник по таблице выше и внести изменения в него. Для новой статьи создать отдельный файл и добавить в индекс статус «Черновик».
2. Проверить ссылки, источники и команды; примеры кода запустить на версиях, указанных в статье.
3. Перенести текст в редактор Хабра и проверить предпросмотр: заголовки, код, таблицы, изображения и ссылки.
4. После сохранения открыть страницу статьи или черновика и сверить её с исходником. Если правки вносились прямо на Хабре, перенести их обратно в этот файл.
5. Обновить в индексе и служебном комментарии исходника ссылку, статус и дату фактической синхронизации, затем скорректировать план серии.

Дата синхронизации означает проверенное соответствие исходника публикации, а не дату первоначального выхода статьи. Для неопубликованного черновика используется `draft_saved_at`; это не дата публичной синхронизации.
