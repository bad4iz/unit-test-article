## Как обновлять статьи

1. Найти актуальный исходник по таблице выше и внести изменения в него. Для новой статьи создать отдельный файл и добавить в индекс статус «Черновик».
2. Проверить ссылки, источники и команды; примеры кода запустить на версиях, указанных в статье.
3. Перенести текст в редактор Хабра и проверить предпросмотр: заголовки, код, таблицы, изображения и ссылки.
4. После сохранения открыть публичную страницу и сверить её с исходником. Если правки вносились прямо на Хабре, перенести их обратно в этот файл.
5. Обновить в индексе и служебном комментарии исходника ссылку, статус и дату фактической синхронизации, затем скорректировать план серии.

`draft_saved_at` — дата сохранения текста в черновике Хабра. Само сохранение черновика не подтверждает, что правки уже доступны читателям.

`synced_at` ставим только после публикации и сверки публичной страницы с исходником. Дата синхронизации означает проверенное соответствие исходника публикации, а не дату первоначального выхода статьи. При повторной сверке обновляем только `synced_at`; `updated_at` меняем, когда меняется опубликованный текст.
